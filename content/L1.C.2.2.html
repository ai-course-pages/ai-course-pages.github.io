Whether the data fits the use

What data is, for this course, is on L1.C.2.1.

Data quality is whether the data fits the use you stated. A large pile can still be a poor fit. A small pile can be a good fit when it is the right information for that use.

The park app's use is one question: is the park busy this afternoon? Data fits that use when an afternoon reader could see, in it, something about how busy the park is then. Four common failures are enough to start with.

  • Missing. The entrance counts skip weekends, and the question is about a Saturday.
  • Mismatched. The file is last winter's photos of the frozen pond, and the question is about a summer afternoon.
  • Noisy. The posts are mostly jokes and arguments about a festival, and almost none of them say whether people are there.
  • Too thin. One photo, from one minute, is all there is. It may be a true photo and still too little to say how the afternoon goes.

Fit and unfit, side by side

Try it on one set

A bakery wants to know how much bread to bake tomorrow, on a normal weekday. The only file on hand is a year of cake orders. Many Mondays are blank. The cakes are for weekend parties.

Say which of the four failures you see, and whether you would call the file fit for tomorrow's bread. The interesting answer names the use first, then the failure. "It is a year of real orders" can be true and still leave the file unfit for bread on a weekday.
