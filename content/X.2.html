Desktop UI

These are desktop harnesses: a window on your computer, rather than a browser tab and rather than a terminal command. The web chats are X.1. The terminal tools are X.3.

AppFromWhat you open
Grok Bot xAI The desktop app. A Bot can use a browser, files, and a terminal on a cloud computer, and the work can continue when the laptop is closed. The same conversation is available from that desktop app. This is not the Grok web chat, and it is not Grok Build.
ChatGPT OpenAI The desktop window for the ChatGPT chat. The web chat is on X.1. Codex, the coding CLI, is on X.3.
Claude Anthropic The desktop window for the Claude chat. The web chat is on X.1. Claude Code, the coding CLI, is on X.3.
Google Antigravity Google A desktop app for running coding agents. It also has an editor and a terminal command. It is listed here because the desktop window is the main way to run it. The CLI page does not repeat it. Gemini, the web chat, stays on X.1.

OpenCode has a desktop window as well. This course lists OpenCode with the CLI tools, on X.3, because that is the form used in a terminal session.

A folder grant for a coding session is still the idea on U1.S.1. These desktop apps are a different door onto that kind of work.
