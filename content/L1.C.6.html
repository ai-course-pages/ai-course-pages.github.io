Four methods

This is a first full pass, still one page. A later pass can give each method its own page, with a longer example. The techniques on L1.C.5 are a different list. Data is L1.C.2.

An algorithm is a procedure that can be followed the same way each time. The four names below are the methods this course introduces first. Machine learning, named on L1.C.1, is the family that supervised and unsupervised learning belong to. It sits inside AI. It is not a second subject.

Decision trees

A decision tree is a series of questions. Each answer picks the next question, or an outcome. For the park posts, one tree could ask whether a post is about the park, whether it describes this afternoon, and whether it says how busy the park was.

For example, a post that says, “The park was quiet at 3pm,” passes all three questions. A post about a dog lost elsewhere does not pass the first question. A post about the park at night does not answer an afternoon question.

Limit: The tree only checks the questions it was given. A post can pass all three and still be mistaken or out of date.

Try it: A note says, “The park was busy yesterday afternoon.” Should this tree use it for today's question?

Worked answer

It passes the park and afternoon questions and says busy. The tree would use it as an example. It is still about yesterday, so it may not describe today. That is a limit of these questions.

Regression

Regression fits a relationship between numbers. Past afternoons can show entrance counts and a person's 1-to-5 rating of how busy the park felt. The method looks for a line, or a simple curve, that stands for that relationship. A new count can then be turned into a rating the line would give.

These small example numbers follow a simple pattern: each 10 more people goes with one more rating point. For a new afternoon with 35 people, use the line “rating = count divided by 10.” The arithmetic is 35 ÷ 10 = 3.5. The line predicts a rating of about 3.5. This is an approximation based on the pattern in the five examples, not a measured rating.

Limit: A line fitted to a few afternoons may not fit other days. A festival, weather, or a different gate count could change how well this pattern applies.

Try it: Using the same line, what rating does a count of 25 predict?

Worked answer

Divide 25 by 10. The result is 2.5, so the line predicts about 2.5. It is an approximation from the example pattern.

Supervised and unsupervised learning

Supervised learning uses examples that already have the answer attached. “Busy” and “quiet” were written by a person. The method learns to assign those labels to a new photo. The labels are data too.

For a small park example, a person has labeled three photos: crowded path, busy; empty path, quiet; crowded playground, busy. A fourth photo of a quiet path is labeled quiet. The method uses these four labeled examples to learn how to label a new photo.

Limit: If the labels are wrong or the examples leave out important kinds of afternoon, the new labels may also be wrong or incomplete.

Try it: A new photo is similar to the two examples labeled “busy.” What label might a supervised method give it?

Worked answer

It might label the new photo busy, because its examples with similar features were labeled busy. That is a prediction from the examples, not a guarantee that the label is correct.

Unsupervised learning has the photos and not the labels. It gathers frames that resemble each other: crowded ones in one cluster, empty paths in another. A person can later decide that one cluster means busy. The method did not start with that word.

For example, imagine four afternoon photos with no labels. Two show many people near the playground; two show an empty path. A method might group the two crowded scenes together and the two empty-path scenes together.

Limit: A group is only a pattern in the examples. It does not name itself. The groups may reflect lighting or camera angle instead of how busy the park is.

Try it: A group contains two photos of the same empty path, taken at different times. What can you say about that group, and what can you not conclude yet?

Worked answer

You can say the method grouped those two similar photos together. Without labels or more context, you cannot conclude that the group means “quiet” or that all quiet parts of the park are represented.

When a method fits the past too closely

A tree or curve can be made to fit every past afternoon exactly. For example, a very winding curve could pass through every count and rating in the table. That does not mean it will predict a new afternoon well. It may have followed small details in those examples that do not repeat. A useful check is to compare its predictions with examples it did not use when it was fitted.

Summary

  • A decision tree follows questions to an outcome. Its result depends on the questions and rules.
  • Regression uses number patterns to estimate a number. A prediction is an approximation.
  • Supervised learning starts with examples that have labels.
  • Unsupervised learning starts without labels and can group similar examples.
  • Each method depends on examples or rules that fit the park question.
