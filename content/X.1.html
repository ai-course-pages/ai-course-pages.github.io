Web models

A harness here is a web chat: you type in a browser, the thread stays in that product, and a long thread can be compressed or compacted as the context window fills. This page names four multi-purpose chats. Plans and model names change. The stable part is who offers the chat, and which course pages assume that kind of thread.

The desktop apps are X.2. The terminal tools are X.3. The map of all three groups is Tools and models.

ChatFromIn this course
Grok xAI The web chat. The desktop app is Grok Bot, on X.2. The terminal agent is Grok Build, on X.3.
ChatGPT OpenAI The web chat. The desktop window is on X.2. The coding CLI is Codex, on X.3.
Claude Anthropic The web chat. The desktop window is on X.2. The coding CLI is Claude Code, on X.3.
Gemini Google The web chat. Google Antigravity, on X.2, is a desktop harness that can run Gemini models. It is not this chat.

Exporting one of these threads into a seed is U1.S.2. Watching a compression or compaction inside the thread is U1.S.3.
