The clocks on a token budget

A product rarely has one bucket of use. It has several clocks. You can be paused by a short clock while a longer one still has room. The exact numbers change. The kinds of clock stay useful.

Read U1.B.1 if one-off messages and threads are still fuzzy. This page uses that difference.

Four clocks

ClockHow to plan
A few hours A burst cap. After a run of messages it can pause you, then clear later the same day.
About a day Often described as 24 hours. In practice it commonly returns sometime the next day, not on a minute you can time. Plan on "tomorrow," and treat the exact hour as loose.
A week A larger allowance. Common on paid plans. A few-hour pause can still stop you in the middle of a week that has room left.
A month The widest ordinary clock. Also common. Hitting it means the shorter clocks are not your problem anymore.

One product can run two or three of these at once. A message that says you are paused is about one clock. Read it for the duration, and for whether it mentions chat, files, or both.

A web chat and a coding CLI

A web chat is built around a box and a transcript. You notice a pause because the page says so. A single question, then a stop, is a normal shape. Attachments and heavy processing are often a separate counter from ordinary chat.

A coding CLI is built around a session. The thread stays open. File reads and command output stay in it. Each step resends that pile, so the same weekly or daily clock moves faster than it does when you ask a few questions in a browser. A long CLI thread is the habit from the previous page, pointed at a clock.

Free, then paid

Use a free model to learn the shape of a task, and to try low and medium effort. Move to a paid model when the free cap, the free quality, or a missing tool is what blocks the work. High effort, and Extra High, on a paid model are the expensive end. A free pass or a low-effort pass should come first, so you are not buying a large reasoning pile for a task you have not yet made clear.

One current illustration is ChatGPT. Ordinary chat can be used without paying. Attachments are capped on their own. After a few files, or after the product has processed a lot of data, that cap can pause you until sometime the next day, even while a plain chat message would still go through. Other products draw this line in other places. The pattern to keep is: chat, files, and heavy processing can be different clocks. The numbers will change, so trust the pause message in front of you over a remembered quota.
