CLI harnesses

These are terminal harnesses. You run them in a shell, they can read a project folder you grant, and a long session is the kind of thread U1.S.1 tells you how to end. The web chats are X.1. The desktop apps are X.2.

ToolFromIn this course
Grok Build xAI The terminal coding agent, started with the grok command. These course pages are edited in that kind of session. It is not the Grok web chat and not Grok Bot.
Codex OpenAI The coding CLI for the ChatGPT side. The web chat and the desktop window are on X.1 and X.2.
Claude Code Anthropic The coding CLI for the Claude side. The web chat and the desktop window are on X.1 and X.2.
OpenCode Open source A terminal coding agent that can use more than one model provider, including Grok. A desktop window also exists. This list keeps OpenCode here, because the terminal session is the form this course means.

Google Antigravity has a terminal command as well. It stays on X.2, because the desktop window is the main way to run it.
