Compress a thread you are staying in

A long thread resends its earlier turns. You can shorten it without leaving. A compression is a shorter text that keeps the decisions and the open task, so later turns resend that text instead of the trail that produced it.

The page before this one, U1.S.2, is for opening a new thread. This page is for a thread you are still using.

If these words are new

A learner with little background would want U1.B.1 first. A follow-up resends the turns the product still keeps. Shortening what is kept is how a long thread gets cheaper while remaining the same chat.

Who writes it

You can ask for the compression. Paste the prompt below when a thread has started to repeat itself. Some products also offer one, or perform one, when a chat grows large. One product may call that compressing the chat. Another may call it a summary, or it may trim older turns. The name belongs to the product. The test is the same: you can read what will stand in for the older turns, and the decisions and the open task are still there.

Accept a compression you can read. If the product shortens the thread where you cannot see the result, ask it to write the compression in the reply so you can check it before you rely on it.

What stays

  • Keep decisions that still bind, names, paths, and the open task.
  • Drop dead ends, repeated attempts, and steps already saved in a file.

A compression can later become the seed you paste into a new thread. Until then it is the standing text of the thread you are in. The model stays the same. The chat stays the same until you choose to leave it.

Suggested exercise

Use a thread you are willing to shorten. The disposable thread on U1.S.2 is enough. Paste this at the end.

This thread is getting expensive to reread. Write a compression that can stand in for the older turns.

Keep the decisions that still bind, and the open task. Leave out dead ends and repeated attempts.

Write it so I can read it before anything is dropped. If you can replace the older turns with this compression, say what will be kept. If you cannot replace them, the compression in your reply is the result.

If the same procedure will come up in other chats, the next page, U1.K.1, is how to pack that procedure as a skill. A skill is meant to be reused, and it is smaller than this thread.
